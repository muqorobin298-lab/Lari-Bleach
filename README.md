Lari Bleach ⚔️

Game lari ala dinosaurus Chrome bertema anime Bleach, dibuat pakai HTML, CSS, dan JavaScript (Canvas).

🔗 Main di sini: https://muqorobin298-lab.github.io/Lari-Bleach/

Fitur
Lompati tiang batu dan tunduki roh terbang
Kecepatan makin tinggi semakin jauh kamu lari
Latar anime berganti tiap 300 poin, dari Senja sampai BANKAI!
Bunyi bip saat lompat, kelipatan 100 poin, dan game over (bisa dimatikan)
Rekor terbaik tersimpan di browser
Bisa dimainkan di laptop (keyboard) maupun HP (ketuk layar dan tombol)
Kontrol
Aksi	Keyboard	HP
Lompat	Spasi / ↑ / W	Ketuk layar atau tombol Lompat
Tunduk	Tahan ↓ / S	Tahan tombol Tunduk
Suara on/off	M	Tombol Suara
